# Apple Vision Pro Landing Page Clone

This project is a visually rich, interactive landing page inspired by the official Apple Vision Pro website. It features advanced animations, responsive design, and a modern UI, closely mimicking Apple's product presentation style.developed by Muhammad Muneer Raja.
## Features
- Hero video and animated sections
- Responsive layout for desktop and mobile
- GSAP and ScrollTrigger animations
- Locomotive Scroll for smooth scrolling
- Sticky, professional footer with social icons
- Canvas-based and image-based visual effects
- All assets (images/videos) are either local or from reliable sources

## Technologies Used
- HTML5, CSS3 (Flexbox, Media Queries)
- JavaScript (ES6+)
- [GSAP](https://greensock.com/gsap/) & [ScrollTrigger](https://greensock.com/scrolltrigger/)
- [Locomotive Scroll](https://locomotivemtl.github.io/locomotive-scroll/)

## Getting Started
1. **Clone or Download** this repository.
2. Open `index.html` in your browser. No build step is required.
3. For best experience, use a modern browser (Chrome, Edge, Safari, Firefox).

## Customization
- To replace images or videos, update the `src` attributes in `index.html`.
- To adjust animations, edit `script.js` (GSAP/ScrollTrigger code).
- For styling, modify `style.css`.

## Responsiveness
- The site is fully responsive. All videos, canvases, and images scale for mobile and desktop.
- Special CSS ensures the hero video, canvas, and key sections look great on all devices.
